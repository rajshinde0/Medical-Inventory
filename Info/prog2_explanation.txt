================================================================================
                        PROGRAM OVERVIEW
================================================================================

This is a comprehensive Medical Inventory Management System that demonstrates
advanced Object-Oriented Programming (OOP) concepts. The system manages:
- Medicine inventory (add, update, sell, remove expired)
- User authentication with role-based access control
- Transaction logging and audit trails
- Reports (low stock, expired medicines)

The system has three user roles:
1. Doctor - Can add and update medicines, view reports
2. Pharmacist - Full access to all operations
3. Nurse - Can sell medicines and view reports
