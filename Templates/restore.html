Expected format

The first row must be exactly this header:

Medicine Name Batch Number Expiry Date Quantity Price Original Quantity
Paracetamol 1004 2027-11-30 9000 3.00 9000

Validation rules

  • Dates YYYY-MM-DD or DD-MM-YYYY; both are normalised to YYYY-MM-DD on import.
  • Numbers Quantity and original quantity must be whole numbers; price may be decimal. Negative values are rejected.
  • Text Medicine names and batch numbers may not contain commas, because the data file is comma-separated and shared with the C++ app.
  • Batches Batch numbers must be unique within the file.
  • All or nothing If any row fails validation, nothing is imported.
